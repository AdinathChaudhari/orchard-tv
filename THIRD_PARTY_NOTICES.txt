extended by testing on a Fire TV Stick 4K Plus), and scripts/detox.sh follows the idea of its tools/disable.sh

tools/tv.py and tools/b64push.py (changes: adb key path and TV host
configuration). Launcher code patterns also informed app/. The Outfit font
from that project is not bundled in Orchard.

4. Open-Meteo weather data (CC BY 4.0) - https://open-meteo.com/
================================================================

Orchard's weather chip fetches the forecast from the Open-Meteo API (free tier, no key). Open-Meteo asks for
attribution under Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/); Settings in the
app shows "Weather data by Open-Meteo.com (CC BY 4.0)". Only city coordinates are sent. No Open-Meteo code is bundled.

5. NOAA solar position equations - https://gml.noaa.gov/grad/solcalc/calcdetails.html
================================================================

app/src/tv/orchard/home/Solar.java reimplements the NOAA Global Monitoring Laboratory sunrise, sunset and solar
elevation equations (Meeus-based). NOAA publishes the method; no NOAA code is copied.
