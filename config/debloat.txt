# Fire TV debloat list: packages that `scripts/detox.sh debloat` disables (pm disable-user --user 0).
# Disabled, never uninstalled: `scripts/detox.sh undo debloat` brings every one back.
#
# Tested on: Fire TV Stick 4K Plus, Fire OS 8 (Android 11). Other Fire OS 7/8 devices: run
# `scripts/detox.sh status` first and expect packages that are absent (they are skipped).
#
# CONSERVATIVE on purpose. A Stick of this model on Fire OS 8.1 is reported to bootloop after aggressive
# com.amazon disables, so launcher-adjacent providers, sync, setup (OOBE) and remote-config packages are left alone.
# Kept on purpose: Alexa (voice button), casting (cast sink, DIAL, whisperplay, fling), Matter, live TV, bluetooth.
# Anything on config/never-disable.txt is refused even if it is added here.
# Fire OS refuses some of these as "protected package"; that is reported and harmless. Layer `background`
# restricts the refused ones instead.
# The firmware-update packages are NOT here; they live in the optional `updates` layer.
# Format: one package per line, `#` starts a comment.
